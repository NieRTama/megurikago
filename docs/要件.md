# 買い物アプリ 要件（2026-11-01 時点）

参考: App Store「ショッピングリズム」（機能のみ参考。名称・文言・画像・デザインは独自にする）

## 決定事項
- 対象: iPhone のみ・家族の私用
- 課金: 作らない（参考アプリの有料機能＝共有・バックアップ・広告なしは全員に開放、広告は入れない）
- サーバー: 安価な方法（Synology 利用 or 無料枠クラウド）→ 未決
- 実装方式: 未決（PWA か ネイティブか）

## 機能
### 定期購入品（棚）
- 棚表示（写真は背景切り抜き）
- 区分: 「そろそろ」=残り7日以内（札「買いどき」）/「まだ先」（札「あと◯日」）
- 購入先タグで絞り込み、並べ替え（期限順/追加順/店ごと）、商品名・メモで検索
- ［＋リストへ］→ 買い物リストへ、「リスト済」表示
- 購入のたびに間隔を学習し次回目安を更新（在庫数入力なし）

### 登録・編集
- 写真（撮る/選ぶ）→ 切り抜き、商品名が空なら写真の文字から読み取り
- 商品名(必須)・購入先タグ・メモ・購入周期(日。1週/2週/1か月/3か月/半年/年のプリセット)・商品リンク
- Amazon / 楽天 / よく使うネットスーパーで検索リンク

### 買い物リスト
- 入力して追加 / 話して追加（品・店・メモに分解）
- チェックで購入済 → 購入履歴に記録、定期購入品なら周期学習
- 購入先で絞り込み、売り場順表示

### マイページ
- 通知オフ警告、購入履歴、共有設定、購入先タグ管理（並び順変更）、よく使うネットスーパー、通知設定、ウィジェットの使い方、バックアップ

### 通知
- 買いどき通知（N日前、既定7）
- 近づいたら: 自動でリストに追加 / 通知のみ
### 共有
- 定期購入品・リスト・履歴を家族で共有、誰かが買うと全員に反映

### その他
- ウィジェット（リスト表示・音声追加）※ネイティブ方式のみ
- 初回チュートリアル（見本写真で1件登録）

## 画面詳細（参考スクショ・録画から。2026-11-02）
参考画像は `docs/ref/`（git 管理外。著作物のため公開リポジトリに入れない）。中身はそのまま真似ず独自デザインにする。

### 入力して追加（下から出るシート）
- 上: 「閉じる」＋タイトル＋「N品 入れました」
- 中央: 入れた品が下から積み上がる一覧（アイコン・品名・購入先・［取り消す］）。空のときは「キーボードの［次へ］で入れて続けて次の品へ」と案内
- 取り消すと「◯◯を取り消しました［戻す］」行と「字を入力欄に戻しました」を表示し、入力欄に文字を戻す
- 下: 購入先タグの横スクロール（＋タグを追加）、入力欄（placeholder「購入先は◯◯…」、マイク）、［＋メモ］、［追加］（空なら無効）
- キーボードの return＝追加して入力欄はそのまま（連続入力）
- 品名から絵文字/イラストを自動で付ける（たまご→卵、ぶたにく→肉）。→ 簡易辞書で実装（後回し可）

### 買い物リスト
- 上: 購入先で絞り込み、「売り場順」トグル、メニュー（追加順 / 店ごとにまとめる）
- 「ネットで探す N件［すべて見る］」帯（リンク付き/ネットの品）
- 店ごとの見出し（「お店の指定なし」など）を折りたためる
- 品の行: アイコン・品名・右に丸いチェック。押すと取り消し線＋チェックになり、少しして「今日買ったもの」に移る
- 初めてチェックしたときに「買ったらチェック。押すと購入が記録され、間違えたら［戻す］」の説明ダイアログを1回だけ出す
- 全部買うと「買うものは全部そろいました」の空表示。「今日買ったもの N件」（開閉できる）に、品名・定期購入品なら「次は11/16ごろ」・購入日（今日▾で変更可）・［戻す］を表示
- タブのバッジ＝未購入件数

### 商品詳細（定期購入品）
- 写真・品名・購入先タグ・「次回予測：あと◯日」・メモ
- 棚での見え方（切り抜き / 元の写真）
- ［買い物リストへ追加］。リストに入っているときは「買い物リストに入っています［外す］」
- 「前回購入 11/2　だいたい14日ごと」＋［＋買った］→「いつ買いましたか？ 今日 / きのう / 日付を選ぶ…（やめる）」→「11/2に買ったと記録しました［取り消す］」
- 購入履歴をすべて見る（N件）→ 日付の一覧・各［削除］（確認ダイアログ「削除すると次回予測も更新されます」）・下に［＋購入を記録］
- Amazon / 楽天 / ほかの店で探す、この定期購入品を削除
- 右上「編集」→ 登録と同じフォーム（写真を変える、棚での見え方の2択プレビュー、購入周期の下に「通知設定を開く」）、［保存］

### 話して追加
- 下からシート「聞いています」、例「スーパーで牛乳2本と卵、ダイソーで電池」、［やめる］［話し終わった］
- 話した内容を品・店・数量/メモに分けてリストに追加（後回し）

### 定期購入品の一覧（棚）の追記
- 検索アイコンで「商品名・メモで検索」欄が出る
- ［＋リストへ］→「リスト済」（棚から外せるのは詳細の［外す］）

## 初期スコープ
棚・登録・買い物リスト・周期学習・通知。
後回し: 写真の文字読み取り/切り抜き、音声入力、共有、ウィジェット（データ構造は共有を前提にしておく）。
