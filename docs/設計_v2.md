# 設計 v2: 自動切り抜き・AI 品名読み取り・音声追加・ウィジェット・使い方ページ

2026-11-03 作成（設計: Opus / 実装: Sonnet / レビュー: Opus）。

参考アプリの録画は「どんな動きをするか」を知るためだけに使う。文言・画面構成・配色は写さず、
このアプリ独自の言葉と見た目（藍・真鍮、`src/ui.tsx` の部品）で作る。

## 前提と決定事項

- 確認は GitHub Actions の未署名 .ipa（AltStore で入れる）で行う。ネイティブ機能は Expo Go では動かないので、
  Expo Go では「この機能はインストール版で使えます」と出して落ちないようにする（`requireOptionalNativeModule` / 遅延 require）。
- Gemini の API キーは各自が「わたし」タブで入力し、`expo-secure-store` にだけ保存する。コード・リポジトリ・
  AsyncStorage の `state:v1`・バックアップ JSON には絶対に入れない。
- 依存の追加は済み: `expo-secure-store`、`expo-speech-recognition`、`@bacons/apple-targets`（app.json の plugins にも追加済み）。
  これ以外の依存は増やさない（前段で `expo-clipboard` と、いらすとや画像を取る `postinstall`（`scripts/fetch-icons.mjs`）を追加済み。
  `npm install` / `npm ci` はいらすとやへの通信が要るが、失敗してもインストールは止まらない）。
- 既存の型チェック（`npx tsc --noEmit`）・`npx expo lint`・`npm run check` は常に通す。

## 1. ネイティブモジュール `modules/megurikago-native`（担当 A）

ローカル Expo モジュール（`npx create-expo-module@latest --local` 相当の構成、iOS のみ。Android は空実装でよい）。

JS 側の窓口は `src/native.ts` だけにする（他のファイルはここ経由で使う）。

```ts
// src/native.ts の公開インターフェース（この形を守る。担当 B はこれだけを呼ぶ）
/** 写真から被写体だけを切り抜き、透過 PNG を Paths.document に保存してファイル名を返す。
 *  被写体が見つからない・iOS 17 未満・Expo Go なら undefined */
export function liftSubject(srcUri: string): Promise<string | undefined>;
/** ウィジェット用データを App Group に書いてウィジェットを更新する。使えない環境では何もしない */
export function setWidgetData(data: WidgetData): void;
export type WidgetData = { items: { name: string; store?: string }[]; count: number; updatedAt: string };
```

Swift 側:
- `liftSubject`: `VNGenerateForegroundInstanceMaskRequest`（iOS 17+、`#available` で分岐）。
  `generateMaskedImage(ofInstances: allInstances, from: handler, croppedToInstancesExtent: true)` を元写真に対して行い、
  長辺 512px に縮小、正方形の透明余白で中央寄せして PNG 保存。ファイル名は `<uuid>.png`、保存先は app の Documents。
  EXIF の向きは縮小時（`CGImageSourceCreateThumbnailAtIndex` の `WithTransform`）に画素へ焼き込み、Vision には `.up` で渡す。シミュレータでは失敗してよい。
- `setWidgetData`: App Group の `UserDefaults(suiteName:)` に JSON 文字列をキー `widget` で保存し、
  `WidgetCenter.shared.reloadAllTimelines()`。
- **App Group 名の解決（重要）**: AltStore / SideStore は署名し直すときに App Group 名へチーム ID を付け足し、
  Info.plist に `ALTAppGroups`（配列）を書き込む。アプリ本体・ウィジェットとも
  「Info.plist の `ALTAppGroups` の先頭 → なければ既定の `group.com.niertama.megurikago`」の順で使う。
  ウィジェットは自分の Info.plist に無ければ親アプリ（`.app`）の Info.plist も見る。

## 2. ウィジェット `targets/widget`（担当 A）

`@bacons/apple-targets` で widget ターゲットを作る（`targets/widget/expo-target.config.js` + Swift）。
App Group の entitlement を本体とウィジェットの両方に付ける。

- 「買うもの」ウィジェット（systemSmall / systemMedium）: 未購入の品名を最大 6 件と件数。データは §1 の `widget` キー。
  タップで `megurikago://list`。データがないときは「アプリを開くと表示されます」。
- 「話して入れる」ウィジェット（systemSmall、ロック画面の accessoryCircular）: マイクの絵とひとこと。
  タップで `megurikago://add?voice=1`。
- iOS 18 以上: コントロールセンター用の `ControlWidgetButton`（`OpenURLIntent` で `megurikago://add?voice=1`）。
  これはアクションボタンにも割り当てられる。`@available(iOS 18, *)` で囲む。
- 見た目は藍 `#2C4A63`・真鍮 `#A9812F`・地色 `#EDEFF2`（`src/ui.tsx` の `C` と同じ）。

CI（`.github/workflows/ios-unsigned-ipa.yml`）の「Strip entitlements」:
`aps-environment` は今までどおり消す。`com.apple.security.application-groups` だけは残してよい（無料 Apple ID でも
AltStore が登録できる）。それ以外が残っていたら失敗させる。ウィジェットの `.appex` が `.app/PlugIns/` に入っていることも
「Package ipa」で確かめる。
未署名ビルド（`CODE_SIGNING_ALLOWED=NO`）では entitlements がバイナリに入らず、AltStore が App Group を登録できない。
そのためビルド後に Frameworks → appex → app の順で `codesign -f -s - --entitlements …` の ad-hoc 署名をし、
app と appex の両方に `application-groups` が入っていることを確かめる。

## 3. 撮影 → 自動切り抜き（担当 B、`src/native.ts` を使う）

`src/store.tsx` の `pickPhoto(camera)`:
- `allowsEditing` をやめる（正方形に切ってからだと被写体が欠ける）。`base64: true` も付けて AI 用に使う。
- 取り込んだ写真で `liftSubject(uri)` を呼ぶ。成功 → その PNG 名を返す。失敗 → 従来どおり JPEG をコピー。
- 戻り値は `{ photo: string; base64?: string }` に変える（base64 は §4 で使う。JPEG の base64）。
  base64 は数 MB になるので、AI で品名を読むとき（`aiPhoto` オンかつ品名が空）だけ取る。
- `pastePhoto`（クリップボード）は残す。
- `Thumb` は `.png` を contain 表示済み（変更不要）。

## 4. 写真から品名を AI で読み取る（担当 B）

- `src/ai.ts`: Gemini REST（`https://generativelanguage.googleapis.com/v1beta/models/${MODEL}:generateContent`、
  ヘッダ `x-goog-api-key`）。`MODEL = 'gemini-flash-latest'` を定数にする。
  - `nameFromPhoto(base64Jpeg, enabled): Promise<string | undefined>`（`enabled` が偽なら送らない。二重の安全装置） — 「日用品・食品の一般的な品名を日本語で短く1つ。
    ブランド名は省く。分からなければ空」と頼み、`responseMimeType: 'application/json'` で `{ "name": string }` を受ける。
  - `splitItems(text, enabled): Promise<string[]>` — 話した文を品ごとに分ける（§5）。`{ "items": string[] }`。
  - キーが無い・同意オフ・通信失敗なら投げずに undefined / ローカル分割を返す。タイムアウト 15 秒（`AbortController`）。
- キー: `expo-secure-store` の `gemini-key`。`getKey()/setKey()` を `src/ai.ts` に置く。
- 設定（`Settings` に追加、既定は false）: `aiPhoto: boolean`、`aiVoice: boolean`。
  **読み込み時に `settings` を既定値とマージする**（`{ ...initial().settings, ...saved.settings }`）。古いデータでも落ちないように。
- 編集画面: 写真を設定したとき、品名が空で `aiPhoto` がオンならだけ送る。読み取り中は品名欄に「読み取り中…」の
  プレースホルダ。結果は品名欄に入れるだけ（保存は人が押す）。

## 5. 音声で品を追加（担当 B）

- `add.tsx` の入力欄の横にマイクボタン。`expo-speech-recognition` で `lang: 'ja-JP'`、`interimResults: true`、
  端末内認識が使えるなら `requiresOnDeviceRecognition: true`。話している間は文字を見せ、止めたら分割して下書きに積む。
- 分割: `aiVoice` オン＋キーあり → `splitItems`。それ以外 → `src/logic.ts` に `splitSpoken(text)` を置く
  （「、」「。」「,」空白・「それと」「あと」で区切る。単独の「と」では区切らない＝トマト対策）。`check-logic.ts` にテスト。
- 声は送らない（文字だけ送る）。これを AI 設定画面の説明に書く。
- `megurikago://add?voice=1` で開かれたら（ウィジェット・コントロールから）、シートを開いてすぐ聞き取りを始める。
- Expo Go では `expo-speech-recognition` が無いので、マイクボタンを出さない（遅延 require + try）。
- `app.json` の `expo-speech-recognition` プラグインに日本語の権限文言（マイク・音声認識）を設定する。

## 6. 設定画面と使い方ページ（担当 B）

- 「わたし」タブに「AI の利用」行 → `src/app/ai.tsx`:
  - 写真から品名: 使う／使わない（説明: 品名が空のときだけ写真を Google の Gemini に送る。個人情報が写った写真は使わない）
  - 音声の分け方: 使う／使わない（説明: 声は送らない。認識した文字だけを送る）
  - Gemini の API キー入力（`secureTextEntry`、保存済みなら「設定済み」と末尾 4 文字だけ表示、消すボタン）。
    キーの取り方（Google AI Studio）を 1 行で。
- 「わたし」タブに「使い方」行 → `src/app/help.tsx`: 開閉できる Q&A。項目は
  棚と周期 / 買い物リスト / 写真とアイコン（いらすとや・切り抜き・AI）/ 音声で入れる / 通知 /
  ホーム画面・ロック画面・コントロールセンター・アクションボタン（ウィジェットの置き方の手順）/ バックアップ。
  各項目の末尾に関連画面へのリンク。文章はこのアプリ独自に書く（参考アプリの文を写さない）。
- ウィジェットデータ: `store.tsx` で list・tags が変わるたびに `setWidgetData` を呼ぶ（保存 effect とは別の effect）。
  自動でリストに入った品は、アプリを開いて `refresh` が走ったときにウィジェットへ反映される。
- マイクの権限: expo-image-picker の `microphonePermission` を `false` にすると NSMicrophoneUsageDescription が消えて
  マイク使用時に落ちるので、文言を入れる。音声認識は端末内認識でも常に許可を求める。

## 検証項目（実機・.ipa で確かめること）

1. 撮影 → 切り抜き PNG がアイコンになる（iOS 17+）。iOS 16 では JPEG のまま。
2. AI キー未設定・オフでは何も送られない。オンで品名が入る。
3. 音声で「牛乳と卵、それとトイレットペーパー」→ AI オフでも「牛乳と卵」「トイレットペーパー」、AI オンで 3 品。
4. ウィジェットが AltStore で入れた状態でリストを表示する（App Group 名の解決が効いているか）。
5. ロック画面・コントロールセンター・アクションボタンから音声入力が始まる。
6. Expo Go で起動しても落ちない。

## 7. 追加の小機能（2026-11-03 追記）

### 7-1. 品を押して画像を拡大
- 買い物リストの行と「今日買ったもの」の行で、アイコン（Thumb）を押すと拡大表示（RN 標準の `Modal`、フェード）。
  中身: 大きな Thumb（画面幅の 7 割程度）・品名・メモ・お店。背景を押すか［閉じる］で閉じる。
- 部品は `src/ui.tsx` に `ZoomThumb`（押せる Thumb ＋モーダル）として 1 つだけ作り、リストで使う。棚のカードは今までどおり詳細へ。
- 拡大モーダルの下部に 7-2 の［このアイコンを外す］／［アイコンを戻す］を置く（いらすとやのアイコンが出る品だけ）。

### 7-2. 合わないアイコンを外す／戻す（この端末だけ）
- `Settings.iconOff: string[]`（既定 `[]`）。中身は品名（`trim()` したもの）。`withDefaults` で既定値が入る。
- `Thumb` は `item.photo` が無く、品名が `iconOff` に入っていれば、いらすとやを使わず頭文字にする。
  `Thumb` は store を読まないので、呼び出し側から `iconOff` を渡すか、`Thumb` 内で `useStore()` を読む（どちらか短い方）。
- 外す・戻すは 7-1 のモーダルと、品の編集画面（写真欄の下、いらすとやのアイコンが当たっているときだけ）に置く。
- 「わたし」タブに「外したアイコン（N 件）」→ 一覧から［戻す］。0 件なら行を出さない。
- 将来の家族共有では `settings` は端末ごと（共有しない）。

### 7-3. 棚の見え方の切り替え（切り抜き / 元の写真）
- 撮影・選択で切り抜けたときは、切り抜き PNG（`photo`）に加えて元の JPEG も `Item.photoOrig` に保存する（切り抜けなかったときは `photo` が JPEG で `photoOrig` は無し）。
  クリップボード貼り付けは `photoOrig` 無し。
- `Settings.shelfView: 'cutout' | 'photo'`（既定 `'cutout'`）。`'photo'` のとき `Thumb` は `photoOrig` があればそれを cover 表示。
- 切り替えは「わたし」タブの見た目の欄（Chip 2 つ）。
- 写真の差し替え・外す・品の削除で `photoOrig` も消す（`deletePhoto` を両方に）。バックアップ JSON は写真を含まないので変更なし。

### 7-4. 通知の「今の状態」の要約
- 「わたし」タブの「お知らせ」見出しの直下に、いまの設定を 1〜2 行の文で出すカード。例:
  - 「買う日の 2 日前の 9 時ごろにお知らせします。近づいた品は通知だけで、リストには自分で入れます。」
  - 「…近づいた品は自動でリストに入ります。」
  - 通知オフ: 「通知はオフです。近づいた品は自動でリストに入ります。」／「…棚の日数で確かめてください。」
  - iPhone 側で通知が許可されていない: 既存の警告カードを優先（要約にも「iPhone の設定で通知が止まっています」を足す）。
- 文を作る関数は `src/logic.ts` の `notifySummary(settings, allowed)` にして `check-logic.ts` でテスト。
