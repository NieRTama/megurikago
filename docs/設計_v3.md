# 設計 v3: 実機で試したあとの改善（2026-11-09）

参考アプリの**動き**に合わせる。文言・見た目はこのアプリのもの（藍と真鍮・`src/ui.tsx` の部品）を使い、参考アプリの文言や画面をそのまま写さない。

## 0. 土台（実装済み。各担当はこれを使う。logic.ts / store.tsx / _layout.tsx の土台部分は書き換えない）

- `Tag.temp?: true` … 一時的なお店。`realTags(tags)` で除ける。`dropTempTags(prev, next)` が `update` と `refresh` のたびに、前は使われていて今は使われなくなった一時的なお店を消す（家族の端末の分を見誤らないため）。`mergeFirst` の名前寄せは一時的なお店を対象にしない
- `TempBadge`（ui.tsx）… 点線の札「一時的」。voice・list の両方で使う
- `Item.area?: string` … 売り場。`areaOf(name, item?)` で決まる（品の指定 → 品名の言葉 → 「その他」）。`AREAS` が売り場の一覧
- `Settings`: `showPics`（品の絵を出す）/ `byArea`（リストを売り場順）/ `areaHintShown` / `areaOrder: Record<tagId, string[]>`。`areaOrderFor(settings, tagId)` が並びを返す
- ルート登録済み: `voice`（formSheet）, `stores`, `notify`, `net`（_layout.tsx）

## 1. タブ画面の下まで届かない（不具合）

ネイティブのタブバーが画面の上に重なるのに、RN の ScrollView は既定で余白を足さない（`contentInsetAdjustmentBehavior` の既定が `never`）。
タブ内の ScrollView すべてに `contentInsetAdjustmentBehavior="automatic"` を付ける。下に固定するボタンは、その部分だけ `SafeAreaView edges={['bottom']}`（react-native-safe-area-context）で包む（`useSafeAreaInsets` はルートで測るのでタブバーの高さが入らない）。FlatList / SectionList にも同じ指定。

## 2. 音声で入れる（担当 A）

- 新しい画面 `src/app/voice.tsx`。開いたらすぐ聞き取りを始める（`continuous: true`）。**［話し終えた］を押すまで止めない**（間があいても止めない）
- 止めたら、話した文を品ごとに分け、**品名・お店・メモ（数量）** に分ける
  - AI オン（`settings.aiVoice` かつキーあり）: `splitItems(text, enabled, storeNames)` が Gemini に聞き、`{name, store?, memo}[]` を返す
  - AI オフ・失敗: 端末内の `parseSpoken(text, storeNames)`（logic.ts・テストつき）
    - 「〇〇で」の〇〇が登録済みのお店か、よくある店の言葉（スーパー・ドラッグストア・薬局・コンビニ・100円ショップ・百均・ホームセンター・Amazon・楽天・ネット）なら、それ以降の品のお店にする
    - 「2本と」のように数量のあとの「と」で区切る（「トマト」は切らない）。区切りは今の `splitSpoken` も使う
    - 品名の後ろの「を」と数量（2本・二箇・3パック など。漢数字は算用数字に、「箇」は「個」に）をメモへ
- 確認の画面: 聞き取った文を上に出し、品ごとに［チェック・品名・お店（選べる）・メモ］。［＋ 品を足す］［もう一度話す（続きを足す）］、下に［N品を追加］
  - 言ったお店が登録済みなら（名前を NFKC・大小無視で比べる）そのお店。無ければ**一時的なお店**（`temp: true`）を作って付け、点線の札で「一時的」と分かるようにする
  - 追加すると買い物リストへ。品名が棚の品と同じなら `itemId` を付ける。お店は**言ったお店を優先**し（その店で買うと言ったため）、言っていなければ棚の品のお店
  - 一時的なお店は、使う行・品が無くなると消える。購入履歴にはお店名が残らない（仕様）
  - 区切り: 句読点（`addsPunctuation`）・「それと」「あと」・数量のあとの「と」・漢字/カタカナ/数字のあとのひらがなの「と」（後ろが「う」なら切らない）。数量は区切りの末尾だけ（「三つ葉」「八丁味噌」は品名のまま）
- `add.tsx` からは音声の部分を外す（入力だけにする）
- ウィジェット・コントロールの URL を `megurikago://voice` に（`targets/widget/*.swift`）

## 3. 買い物リスト（担当 B）

- 下に 2 つのボタン［話して追加］（→ `/voice`）［入力して追加］（→ `/add`）
- ［売り場順］スイッチ（`settings.byArea`）。オンにすると、お店ごとのまとまりの中を売り場の見出しで分け、`areaOrderFor` の順に並べる。初めてオンにしたときだけ、お店ごとに並びを変えられることを案内し、［並びを見る］で `/stores?tab=area` へ
- 一時的なお店は見出しに点線の札「一時的」
- 上部に「ネットで探す（N件）」の帯 → `/net`: 未購入の行ごとに Amazon・楽天・（設定があれば）ネットスーパーの検索を開く

## 4. 品の詳細（担当 B）

- ［＋買った］で、画面の中に「いつ買いましたか？」を開く: ［今日］［きのう］［日付を選ぶ…］［やめる］。日付は今の `Alert.prompt` の入力で可
- 履歴は最新 3 件 + 「購入履歴をすべて見る（N件）」→ `/history?item=<id>`
- ネットで探す: ［Amazon で探す］［楽天で探す］を横並び、［ほかの店で探す］でネットスーパー・登録したリンク
- 編集画面（item/edit.tsx）で売り場を選べる（チップ。未選択は「おまかせ」= 品名から推す）。お店の選択肢は `realTags`

## 5. 購入履歴（担当 B）

- 品名で検索、月で絞り込み（その月のチップ。［すべて］あり）、月ごとの見出しと件数
- 行ごとに日付を押して変更（`askDate`）、削除（確認つき）
- `?item=<id>` で開いたらその品だけ。下に［＋ 購入を記録］

## 6. お店と売り場の順（担当 B・`src/app/stores.tsx`）

- 上で［お店］［売り場の順］を切り替え（`?tab=area` で後者から開く）
- お店: 入力欄＋［追加］、並べ替え（↑↓）、名前を押して変更、削除（確認）、先頭に動かせない「お店の指定なし」。一時的なお店は出さない
- 売り場の順: お店を押すと、その店の売り場を ↑↓ で並べ替え。［最初の順に戻す］。並びは `settings.areaOrder[tagId]`（この端末だけ）
