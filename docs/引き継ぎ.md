## 技術上の注意（相談役の指摘）
- expo-notifications は prebuild で `aps-environment` を付ける → 無料 Apple ID だと署名に失敗。config plugin か CI で除去。ローカル通知のみ。iOS の予約上限は64件 → 1日1回にまとめるか、起動時に予約し直す
- CI: `expo prebuild` → `xcodebuild -sdk iphoneos -configuration Release CODE_SIGNING_ALLOWED=NO` → `Payload/` を zip して .ipa を artifact に（Debug だと JS バンドルが入らない）
- 共有は Firebase JS SDK（modular）。@react-native-firebase は使わない（Expo Go 非対応、AltStore の bundle ID 書き換えとずれる）。Auth は `getReactNativePersistence(AsyncStorage)`。参加コードで家族IDに入る方式と Security Rules を作る。Associated Domains / Sign in with Apple は不可
- AltStore 無料枠: 3アプリ（AltStore 自身を含む）・App ID は週10個まで・7日ごとに再署名。PC 不要の SideStore も選択肢として伝える
- 音声・Vision・ウィジェットは Expo Go 不可。それまでは Expo Go で確認
